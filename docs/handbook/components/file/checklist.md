# 压测与回归检查清单（Release Checklist）

在合并存储引擎改动分支前，请逐项核对以下基准指标：

## 1. 持久性与崩溃恢复

- [x] 断电模拟测试（`crash-monkey` 500 轮随机掉电）零丢数、零半写页
- [x] WAL 校验和（CRC32C）损坏时能够准确截断尾部并输出恢复位点日志
- [x] 快照导出与跨节点恢复后状态机哈希一致

## 2. 尾延迟与空间放大边界

| 指标项 | 准入红线 | 本轮实测值 |
| :--- | :--- | :--- |
| 顺序写吞吐 (16 线程) | >= 180 MB/s | 214 MB/s |
| 随机点查 P99 (缓存命中) | <= 120 us | 84 us |
| Leveled Compaction 空间放大 | <= 1.15x | 1.09x |
