```garden chart
title: 三种版面区域的宽度上限
xLabel: 版面区域
yLabel: 最大宽度
unit: px
data:
  - x: 普通正文列
    y: 740
  - x: 宽幅配图区
    y: 1040
  - x: 多列宽表格
    y: 1340
caption: 点击「查看数据表」可展开完整数值表格。
```

- **什么时候用**：一组已经算好的同单位数字，想让读者一眼看出长短比例。
- **什么时候不用**：数字会随读者调整参数而变化时用[可调公式与参数](/garden/components/interactive)；图表下方已经自带可展开的数据表，同一小节里不需要再重复放一张相同数字的表格。

可以这样对 AI 说：

````markdown
```garden
画一张条形图比较普通正文列（740px）、宽幅配图区（1040px）和多列宽表格（1340px）的宽度上限。
```
````

## 字段说明

围栏写 ` ```garden chart `（编辑器代码片段触发词 `;gchart`）。可以用 `data: [{ x, y, label? }]` 写行数据，也可以用 `x` + `series` 写列数据。

| 字段 | 是否必填 | 默认值 | 取值与限制 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `title` | 建议填写 | 无障碍标签默认 `"图表"`（不渲染可视标题） | 字符串 | 图表上方标题 |
| `data` | 与 `series` 二选一 | `[]` | `{ x, y, label? }[]`（至少 `2` 项，建议 `2`～`8` 项；顶层写未知键名或 YAML 格式错误时报 `garden-yaml` 错误） | 条目数组：`x` 为左侧名称，`y` 为数值，`label` 默认拼接 `y` 与 `unit` |
| `series` | 与 `data` 二选一 | 无 | `{ name?, data: number[] }[]`（至少 `2` 个数值点） | 配合 `x`（标签数组）使用的数值序列，取 `series[0].data` 渲染条形 |
| `x` | 可选 | `["1", "2", ...]`（按序号递增） | 字符串或字符串数组 | 配合 `series` 时为各项标签数组；单独写字符串且未填 `xLabel` 时作为数据表首列表头 |
| `type` | 可选 | `"bar"` | `"bar"` | 图表类型（水平条形图） |
| `unit` | 可选 | `""` | 字符串 | 未显式填写 `data[].label` 时在数值右侧追加的单位 |
| `xLabel` | 可选 | 字符串 `x` 或 `"项目"` | 字符串 | 可展开数据表第一列的表头 |
| `yLabel` | 可选 | `"数值"` | 字符串 | 可展开数据表第二列的表头 |
| `caption` | 可选 | 无 | 字符串 | 图表底部的图注 |
