# Intelligent UI 组件规格

这是 [Intelligent UI 写作层](./intelligent-ui.md) 第 7 节组件目录的完整规格：每个组件的属性、子元素、外观、交互和静态快照。`ui/core/catalog.mjs` 按本文实现；两者不一致时，先改本文，再改代码。组件清单、`garden ui prompt` 里的组件说明和校验器都从 `catalog.mjs` 生成。

---

## 1. 通用约定

### 1.1 属性怎么写

| 写法 | 例子 | 说明 |
| --- | --- | --- |
| 字符串 | `label="序列长度"` | 双引号 |
| 数字、布尔 | `min={1}`、`reset={true}` | 放在 `{}` 里 |
| 表达式 | `value={mem / 1024}` | 按 [表达式文法](./intelligent-ui.md#63-表达式文法) 求值，每次渲染重算 |
| 布尔简写 | `reset` | 等于 `reset={true}` |

属性表里标"字面量"的只能写字符串、数字或布尔，不能写表达式：`State` 的值、`bind`、`as`、`index`、`name`、`src`、`sweep`、`scale`、`snap`、`style`、`samples`、`autoplay`。其余属性都可以写表达式。

类型说明里的写法：

- **状态名**：一个已在 `State` 里声明的名字，写成字符串，如 `bind="batch"`。
- **名字**：小写字母开头，只含字母、数字、下划线，不能和函数名、`PI`、`E` 重名。
- **格式**：见 1.3。
- **tone**：见 2.3。

未知属性、类型不对、缺必填，报 `ui-prop`。

### 1.2 子元素

- 每个组件只接受表里列出的子元素。`Step` 只能在 `Steps` 里，`Tab` 只能在 `Tabs` 里，`Row` 只能在 `Table` 或 `Grid` 里，`Line` / `Area` / `Bar` / `Point` 只能在 `Chart` 里，`Hotspot` 只能在 `Image` 里。放错报 `ui-children`。
- "可含正文"指子元素可以是 Markdown 段落、列表和其他展示组件。
- `If` 和 `Each` 是透明的：它们的子元素按它们所在位置的规则校验。例如 `Grid` 里可以写 `<Each>`，`Each` 里放 `Row`。

### 1.3 格式

`format` 属性和同名格式函数用同一套规则：

| 格式 | 规则 | 例子 |
| --- | --- | --- |
| 不写 | JavaScript 的 `String(x)`，最短往返表示 | `0.30000000000000004` |
| `number` | 同"不写" | |
| `fixed:N` | 保留 N 位小数 | `fixed:2` → `3.14` |
| `percent` / `percent:N` | 乘 100，保留 N 位小数（默认 0），加 `%` | `0.125` → `13%` |
| `bytes` | 二进制单位 B、KiB、MiB、GiB、TiB、PiB，取让数值落在 1–1024 之间的单位，最多 3 位有效数字，去掉末尾的 0 | `536870912` → `512 MiB` |
| `si` | 十进制单位 K、M、G、T，最多 3 位有效数字 | `32768` → `32.8K` |
| `thousands` | 整数部分加千分位，小数部分原样 | `32768` → `32,768` |

非有限数（`Infinity`、`NaN`）和 `undefined` 一律显示"—"。

### 1.4 无障碍

- 交互控件都用原生元素：`input type="range"`、`button`、`select`。每个控件都有可读的名字（来自 `label` 或 `title`）。
- 所有可聚焦元素的焦点样式：2px 焦点蓝描边（浅色 `#0285ff`，深色 `#3a83f7`），外扩 2px；滑杆的焦点框画在整条轨道外，外扩 3px。
- 随状态变化的数字（`Stat`、`Meter`、行内插值所在的段落、`Grid` 和 `Table` 的说明区）放在 `aria-live="polite"` 区域。
- `Chart` 附一份视觉上隐藏的数据表，供读屏软件读取。

### 1.5 动效

动效的时长取自 ChatGPT Intelligent UI 的实测（Thesys 的逆向文章）：新出现的行滑入 0.42s，图表画出 1.8s。

- 数值变化不做滚动或补间动画，直接显示新值。
- `Steps` 翻页时内容上移 4px 并淡入，420ms；`autoplay` 两步之间至少 800ms。
- `Chart` 第一次滚进视口时，折线在 1.8s 内画出，柱子 0.6s 从基线长出，面积和散点 0.7s 淡入。只画一次，之后数据变化直接显示。
- 进度条宽度变化 300ms；按钮、标签、开关的颜色和位置变化 150ms；按下按钮缩到 0.96–0.98。
- `prefers-reduced-motion: reduce` 时取消所有动画和过渡，`autoplay` 不启动。

## 2. 视觉基础

### 2.1 外框

一块 `ui` 渲染成：

```text
<figure class="garden-ui" id="ui-<id>">
  <div class="garden-ui-body">……组件……</div>
  <figcaption>caption</figcaption>
</figure>
```

外观复刻 ChatGPT 的 Intelligent UI。数值取自两处，浅色和深色都有：OpenAI 发布页里 Intelligent UI 演示的样式（`--iui-*` 变量，2026-10-10 读取），和 chatgpt.com 组件样式里的 token（`--d-*`、`--color-*`）。站点的纸面 token 和强调红不进块里；块在任何主题下都像嵌在 ChatGPT 回答里的一张卡片。

外框跟 ChatGPT 的做法一样：回答铺在会话背景上，交互部分只用细描边围起来，不另铺一块白底。圆角 8px（与 2026-10-11 的并排裁图一致），`1px solid` 边框（浅 `#0000001a`，深 `#ffffff1a`），底色透明，上下外边距 28px，内边距 16px（480px 以下 14px）。`figcaption` 是卡片里的说明小字：13px、次要文字色、行高 1.65，没有分隔线。图表放在一块内嵌底上（浅 `#f4f4f4`，深 `#212121`），默认折线是 `#0285ff`，点不多时带圆点。滑杆是占满宽度的 24px 全圆角轨道（浅 `#0d0d0d1f`，深 `#ffffff26`），里面一个内缩 3px 的 18px 实心圆点（浅 `#333`，深 `#ededed`），不画已走过的部分。

### 2.2 字体与尺寸

| 用途 | 规格 |
| --- | --- |
| 字体 | ChatGPT 的系统字体栈：`ui-sans-serif, -apple-system, system-ui, "Segoe UI", Helvetica, …`，补上 `"PingFang SC"` 等中文字体；代码和格子用 `ui-monospace, "SF Mono", Menlo, …` |
| 块内正文 | 15px，行高 1.65，主文字色 |
| 小标题（`Card`、`Steps`、`Checklist` 的标题） | 16px、600 |
| 控件标签 | 14px，次要文字色；控件的当前值 15px、600、等宽数字 |
| 说明、注释、图例 | 13px（图例 12px），次要文字色 |
| `Stat` | 标签 12px 大写、字距 0.04em；数值 `sm` 18px、`md` 24px、`lg` 32px，600 |
| 间距 `gap` | 0 / 4 / 8 / 12 / 16px，对应 0–4，默认 3。ChatGPT 的间距也是 4px 一档 |
| 圆角 | 外框 16px；内嵌卡片、代码、图片 12px；分段控件 12 / 10px；格子 8px；按钮、标签、徽标、滑轨全圆 |
| 阴影 | 只用在分段控件选中项（`0 1px 4px -1px #0003`）和浮层（`0 2px 6px #00000014`） |

颜色（浅 / 深）：

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主文字 / 次要 / 更淡 | `#171717` / `#666` / `#888` | `#ededed` / `#cdcdcd` / `#afafaf` |
| 边框 / 细线 / 控件描边 | `#e5e5e5` / `#eee` / `#ddd` | `#ffffff26` / `#ffffff0d` / `#fff3` |
| 内嵌面 / 标签底 | `#f5f5f5` / `#f4f4f4` | `#2a2a2a` / `#303030` |
| 实心（主按钮、勾选、选中标签） | `#171717` 底，`#fff` 字 | `#ededed` 底，`#0d0d0d` 字 |
| 进度条 | `#5b806d`，轨道 `#f5f5f5` | `#40c977`，轨道 `#303030` |
| 焦点 | `#0285ff` | `#3a83f7` |

### 2.3 tone

tone 映射到 ChatGPT 的语义色，定义在 `ui/react/ui.css`。深色主题跟随 `:root[data-theme="dark"]`。

| tone | 中文名 | 用途 | ChatGPT 语义 | 浅色：字 / 底 | 深色：字 / 底 |
| --- | --- | --- | --- | --- | --- |
| `plain` | — | 默认 | 主文字 | `#171717` / 透明 | `#ededed` / 透明 |
| `accent` | 重点 | 唯一的焦点 | info | `#0169cc` / `#0285ff1a` | `#66b5ff` / `#0285ff26` |
| `muted` | 次要 | 次要信息 | 次要文字 | `#666` / `#f5f5f5` | `#cdcdcd` / `#2a2a2a` |
| `new` | 新算 | 这一步新算、新增 | success | `#008635` / `#04b84c1f` | `#40c977` / `#04b84c26` |
| `cached` | 读缓存 | 读缓存、不必重算 | 次要文字 | 同 `muted`；格子改为虚线描边、无底色 | 同左 |
| `waste` | 浪费 | 重复计算、浪费 | danger | `#ba2623` / `#fa423e1a` | `#fa423e` / `#fa423e29` |
| `same` | 相同 | 和别处相同（如 ECB 的重复块） | discovery | `#8046d9` / `#924ff71a` | `#be95fa` / `#924ff726` |

图表系列用每种 tone 的实色：`plain` 为实心色，`accent` `#0285ff`，`new` `#00a240`（深 `#04b84c`），`waste` `#e02e2a`（深 `#fa423e`），`same` `#924ff7`，`muted` / `cached` 为更淡的文字色。

静态快照里，有 tone 的格子在值后加括号标注：优先用 `legend` 里的说明，没有就用中文名。`plain` 不标注。

一块里 `accent` 和 `waste` 合起来最多用在两个焦点上。

### 2.4 窄屏

- 480px 以下：外框内边距 14px；`Columns` 自动叠成一列；`Table` 和 `Grid` 放进横向滚动容器；`Chart` 高度乘 0.8，最低 140px，x 轴刻度按标签宽度抽稀，不重叠。
- 任何组件都不写固定像素宽度。

### 2.5 错误卡片与想法卡片

只出现在本地预览、后台草稿预览和编辑器插件里：

- 错误卡片：正文区铺 danger 浅底，标题"这块交互有错误"用 danger 字色，下面是诊断列表（code、行号、说明）；`figcaption` 照常显示 `caption`。
- 想法卡片（`intent`）：画成 ChatGPT 里用户消息的气泡，蓝色浅底（浅 `#eaf2ff`，深 `#133463`），圆角 18px，右上角"未编译"徽标；没有外框。

## 3. 状态与逻辑

### State

声明状态和默认值。不渲染任何东西。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 任意名字 | 字面量：数字、字符串、布尔 | 至少一个 | 名字即状态名，值即默认值。负数写成 `{-1}` |

- 一块里可以有多个 `State`，名字在 `State`、`Let`、`Data` 之间不能重复。
- 静态快照：不输出。

```text
<State batch={1} seq={4096} mode="mutex" detail={false} />
```

### Let

声明派生值。不渲染任何东西。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 任意名字 | 表达式，任意类型 | 至少一个 | 名字即派生值名 |

- 可以引用状态、别的 `Let`、`Data`。按依赖排序求值，成环报 `ui-cycle`。
- 数据数组也用 `Let` 写（见 [6.7](./intelligent-ui.md#67-数据)）。
- 静态快照：不输出。

```text
<Let mem={2 * 32 * 8 * 128 * seq * batch * 2} gib={mem / 1073741824} />
```

### If

条件为真时渲染子元素。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `test` | 表达式→任意 | 是 | 按 JavaScript 真值判断 |

- 子元素：透明（见 1.2）。
- 静态快照：按默认状态求值，只输出为真时的子元素。

### Each

循环渲染子元素。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `of` | 表达式→数组 | 是 | 不超过 200 项，超出报 `ui-limit` |
| `as` | 字面量：名字 | 是 | 当前项的名字 |
| `index` | 字面量：名字 | 否 | 从 0 开始的序号 |

- 子元素：透明。
- 静态快照：按默认状态展开。

```text
<Each of={range(0, rows)} as="i">
  <Row label={"t" + (i + 1)} cells={["k" + (i + 1), "v" + (i + 1)]} />
</Each>
```

## 4. 布局

### Stack

纵向排列。块的正文本身就是一个 `Stack`，只有需要改间距或在 `Card` 里分组时才写。

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `gap` | 0–4 | 否 | 3 | 子元素间距 |

- 子元素：可含正文。
- 静态快照：依次输出子元素。

### Columns

自动换行的多列。作者会说："并排放""左右对比""两栏"。

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `gap` | 0–4 | 否 | 3 | 列间距 |
| `min` | 160–400 | 否 | 220 | 每列最小宽度（px）；放不下就换行 |

- 子元素：可含正文，每个子元素占一列。最多 4 个子元素。
- 外观：CSS grid，`repeat(auto-fit, minmax(min(var(--min), 100%), 1fr))`。
- 静态快照：依次输出每列。

### Card

带边框的分组。作者会说："一边一个框""分组"。

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | 字符串 | 否 | — | 卡片标题 |
| `tone` | `plain` `accent` `muted` | 否 | `plain` | 边框和标题颜色 |

- 子元素：可含正文。
- 外观：无边框的内嵌面，圆角 12px，内边距 14px，底色为内嵌面色；`title` 16px、600，下方间距 8px。`tone` 不是 `plain` / `muted` / `cached` 时，底色换成该 tone 的浅底、标题换成该 tone 的字色（例如 `accent` 是浅蓝底）。
- 静态快照：标题加粗成一行，下面是内容。

```text
<Columns>
  <Card title="Mutex">读者和写者一个接一个，共 **{(readers + 1) * 10} ms**。</Card>
  <Card title="RwLock" tone="accent">读者一起读，写者再独占，共 **20 ms**。</Card>
</Columns>
```

### Tabs / Tab

标签切换。作者会说："切换着看""分几个视角"。

`Tabs`：

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `bind` | 字面量：状态名（数字） | 否 | 当前标签序号，从 0 开始。不写时自己管 |

`Tab`：

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | 字符串 | 是 | 标签文字 |

- 子元素：`Tabs` 只含 2–6 个 `Tab`；`Tab` 可含正文。
- 外观：一排全圆角的标签片，间距 7px，13px；未选中为标签底色，选中为实心底、反色字。点击区域不小于 28px 高。
- 交互：ARIA tabs 模式；左右方向键切换，Home / End 跳到首尾。
- 静态快照：依次输出每个 `Tab`，标题加粗成一行。

### Steps / Step

一步一步看。作者会说："一步步走""停在某一步""第几拍"。

`Steps`：

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `bind` | 字面量：状态名（数字） | 否 | — | 当前步序号，从 0 开始。不写时自己管 |
| `autoplay` | 字面量：数字（毫秒，≥ 800）或 `false` | 否 | `false` | 自动前进的间隔；到最后一步停下 |

`Step`：

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | 字符串 | 是 | 这一步的名字 |

- 子元素：`Steps` 只含 2–24 个 `Step`；`Step` 可含正文。
- 外观：顶行左边是当前步标题（16px、600），右边是"2 / 5"（12px、次要文字色）；下面一条 3px 进度条，长度为已走到的步数占比；中间是当前步内容；底行是 36px 的圆形"上一步""下一步"按钮（细描边、箭头图标，读屏名称仍是"上一步""下一步"）和一排可点的 8px 圆点，当前步为实心色。内容区高度取最高的一步，翻页时版面不跳动。
- 交互：按钮、小方点，以及焦点在 `Steps` 内时的左右方向键。`autoplay` 时显示"暂停 / 播放"按钮，离开视口暂停，用户一操作就停止自动播放。
- 静态快照：有序列表，每项是"标题：内容"，内容按 `bind` 状态等于该步序号时求值。

## 5. 输入

### Slider

拖动改一个数。作者会说："拧""调""拖一下""从 1 到 32"。

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `bind` | 字面量：状态名（数字） | 是 | — | |
| `label` | 字符串 | 是 | — | |
| `min` | 数字 | 是 | — | |
| `max` | 数字 | 是 | — | 必须大于 `min` |
| `step` | 数字 | 否 | `min`、`max` 都是整数时为 1，否则为 (max − min) / 100 | 线性刻度下的步长 |
| `scale` | 字面量：`linear` `log` | 否 | `linear` | `log` 要求 `min > 0` |
| `snap` | 字面量：`none` `int` `pow2` | 否 | `log` 且 `min`、`max` 都是 2 的幂时为 `pow2`，否则为 `none` | 对数刻度下的取值方式：`pow2` 只停在 2 的幂上 |
| `format` | 格式 | 否 | — | 显示当前值 |
| `unit` | 字符串 | 否 | — | 跟在值后面 |

- 默认值（`State` 里的值）必须在 `[min, max]` 内，`snap="pow2"` 时必须是 2 的幂，否则报 `ui-prop`。
- 外观：一行里左边是 `label`（14px、次要文字色），右边是格式化后的当前值和 `unit`（15px、600）；下面是占满宽度的 24px 全圆角轨道（浅 `#0d0d0d1f`，深 `#ffffff26`），里面一个内缩 3px 的 18px 实心圆点（浅 `#333`，深 `#ededed`），轨道不画已走过的部分，与 ChatGPT 的滑杆一致。原生 `input type="range"` 的点击区域扩到 38px 高。
- 交互：原生滑杆，方向键按步长移动；`pow2` 时每次移动一个 2 的幂。
- 静态快照：`label：当前值 unit（网页中可调，范围 min–max）`。

```text
<Slider bind="seq" label="序列长度" min={1024} max={32768} scale="log" format="thousands" />
```

### Choice

从几个选项里选一个。作者会说："选一种""在 A 和 B 之间切换"。

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `bind` | 字面量：状态名 | 是 | — | |
| `label` | 字符串 | 是 | — | |
| `options` | 表达式→数组 | 是 | — | 元素是数字或字符串，或 `{ value, label }`；2–8 项 |
| `style` | 字面量：`segmented` `select` | 否 | 不超过 5 项时 `segmented`，否则 `select` | |

### Chart / Line / Area / Bar / Point

曲线和柱状图。作者会说："画条曲线""随 x 变化""柱状图""把这组数据画出来"。

`Chart` 有两种模式，`sweep` 和 `data` 必须写且只能写一个：

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `sweep` | 字面量：状态名（数字） | 二选一 | — | 函数模式：横轴扫过这个状态的范围 |
| `data` | 表达式→数组 | 二选一 | — | 数据模式：每个元素是一行对象 |
| `x` | 表达式 | 数据模式必填 | — | 逐行求值，行字段在作用域内 |
| `from` / `to` | 数字 | 否 | 绑定该状态的 `Slider` 的 `min` / `max` | 函数模式的范围；没有对应的 `Slider` 时必填 |
| `scale` | 字面量：`linear` `log` | 否 | 跟随 `Slider` | 横轴刻度 |
| `samples` | 字面量：数字 | 否 | 64 | 函数模式取样点数，≤ 200；`Slider` 为 `pow2` 时改为取每个 2 的幂 |
| `yScale` | `linear` `log` | 否 | `linear` | |
| `yMin` / `yMax` | 表达式→数字 | 否 | 自动 | |
| `xLabel` / `yLabel` | 字符串 | 否 | — | 坐标轴名 |
| `xFormat` / `yFormat` | 格式 | 否 | 取第一条系列的 `format` | |
| `height` | 120–480 | 否 | 200 | px |

系列（子元素，1–4 个）：

| 系列 | 属性 | 模式 |
| --- | --- | --- |
| `Line` | `y`（表达式，必填）、`label`、`tone`、`format` | 两种都可以 |
| `Area` | 同 `Line` | 两种都可以 |
| `Bar` | 同 `Line` | 只用于数据模式；`x` 当作类别 |
| `Point` | 同 `Line` | 只用于数据模式 |

- 函数模式：每个取样点上，`sweep` 状态取该点的值，其余状态取当前值，重算 `Let` 后求 `y`。数据模式：逐行求 `x` 和 `y`，`Line` / `Area` 按 `x` 排序连线。
- 外观：自绘 SVG，宽度占满。y 轴 4–5 个刻度，x 轴 4–6 个刻度，取整齐的数；对数轴刻度取 10 的幂，跨度不足两个数量级时取 2 的幂。刻度文字 12px、系统字体、更淡的文字色，网格线为细线色，x 轴线为边框色；x 轴刻度按标签宽度抽稀，任何宽度下都不重叠。系列默认颜色依次为 `plain`、`accent`、`new`、`same` 的实色（见 2.3）；`Line` 2px、圆头，`Area` 用系列色 10% 透明度填充加 2px 描边，`Bar` 顶部圆角、之间留 2px，`Point` 半径 3px。多于一条系列时左上角显示图例（8px 圆点）。函数模式在当前值处画一条虚线竖线，每条线上一个半径 4px 的空心点，旁边标出当前 y 值（12px、600）。悬停提示是圆角 10px 的浮层，带细边框和阴影。第一次进入视口时按 1.5 节的时长画出。
- 交互：悬停或触摸时显示十字线和提示框，列出 x 和每条系列的 y（按格式）。图表可以聚焦，左右方向键在取样点之间移动。
- 静态快照：函数模式写成 6 个等距取样点的表格（对数轴按对数等距）；数据模式写成数据表。表前一行"（网页中为可交互图表）"。

```text
<Chart sweep="seq" yLabel="KV 显存">
  <Line y={mem} label="batch = 当前值" format="bytes" />
  <Line y={mem / batch * 32} label="batch = 32" format="bytes" tone="muted" />
</Chart>
```
