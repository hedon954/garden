# 窗台香草浇水记录

三只盆放在北向窗台，每周记一次。土面下两指还湿就不浇。

## 怎么记

- **日期**：写周几，方便看出间隔。
- **水量**：用量杯，单位毫升。
- **土况**：干、半干、湿三档。

## 前四周

| 周 | 罗勒 | 薄荷 | 土况 |
| --- | --- | --- | --- |
| 第 1 周 | 120 ml | 80 ml | 干 |
| 第 2 周 | 150 ml | 80 ml | 半干 |
| 第 3 周 | 150 ml | 100 ml | 半干 |
| 第 4 周 | 180 ml | 100 ml | 湿 |

## 换算

量杯不在手边时，用普通玻璃杯估一下：

```python
def cups(ml):
    # 一个普通玻璃杯大约 250 ml
    return round(ml / 250, 1)

print(cups(180))  # 0.7
```

## 小结

罗勒长得快，水量每周加一点；薄荷保持湿润就行。盆底托盘里的积水 `30` 分钟后倒掉。
